# V2 桌面连接实例

P5 已实现实例管理、浏览器登录、远程账号 API 和设备会话撤销。远程切换的链路仅在合成环境验证，生产入口保持关闭；真实 Cursor 多设备续期实验尚未完成，不能将其作为已支持能力。验证结果见 [P5 报告](plans/p5-verification.md)，设计见 [ADR 0007](adr/0007-p5-connected-desktop.md)。

## 连接与使用

1. 部署并初始化 V2 服务端，升级到包含 `0003_devices` 的版本，按 [Web 文档](v2-web-operations.md) 配置 HTTPS。
2. 打开桌面，点击侧栏“本地 · 切换实例”。填写名称和实例根地址，例如 `https://panel.example.com`。首版不支持子路径部署或 HTTP 外部地址；HTTP 回环地址仅用于本机开发。
3. 点击“浏览器登录”。系统浏览器打开该实例，登录后核对实例地址、用户和设备，点击“允许连接此设备”。完成后可关闭回调页，返回桌面；面板会自动进入对应实例。
4. 选择个人或团队空间。列表显示服务端最后成功快照与时间；明细、刷新及账号维护均按当前角色与授权执行。远程成员、标签、审计和实例管理复用现有 API；邀请链接指向该远程实例。
5. 在“实例连接”选择其他实例，或点击“返回本地账号”。本地与远程数据库互不导入或同步；切换后清空旧空间与查询结果。应用重新启动或界面重新载入时默认显示本地账号，保存的远程连接可以重新打开。

远程实例当前不提供桌面切换按钮。实例支持相同的 API 主版本并声明 `device_sessions` 才能登录；未知可选字段可忽略，协议不兼容时显示升级提示并拒绝继续请求。远程操作不直接访问 Cursor，本地托盘调度只处理本地账号。服务端当前仍通过手工刷新或按需明细取最新额度，周期调度没有在 P5 中增加。

## 设备登录与撤销

设备登录有效期最长 30 天。服务端保存随机令牌哈希，桌面把长期令牌放在系统凭证库，前端只接收公开业务数据；每次远程请求重新检查会话及账号权限。同一台安装重新登录撤销其上次设备会话。设备会话不受普通网页会话数量上限挤出，两类登录各保留最多 20 个活动会话。

网页或远程桌面的“个人设置 → 登录会话”展示网页会话及桌面设备，均可撤销。修改密码、运维恢复密码或停用用户会撤销其所有设备会话。撤销当前设备后，下次请求会清空账号界面并引导重新登录。

“断开登录”尝试撤销远端设备会话并删除本机保存的令牌；“移除连接”额外删除连接名称与地址。如果实例离线，界面会明确显示远端撤销未确认，此时仍应登录实例网页，在个人设置中撤销对应设备。系统凭证库无法删除令牌时显示错误，不虚报成功。

## 失败恢复

| 状态 | 恢复方式 |
| --- | --- |
| 浏览器登录超时或取消 | 回到实例连接，重新点击“浏览器登录”；旧授权码不能重复使用 |
| 系统凭证库锁定 | 解锁 Keychain / Credential Manager 后重试，不创建明文令牌文件 |
| 设备登录到期或被撤销 | 重新浏览器登录，账号授权以当前服务端状态为准 |
| 远程离线 | 保留已载入快照并显示错误；重载或切换连接后不从磁盘恢复远端账号缓存 |
| 协议不兼容 | 升级服务端或桌面，期间可返回本地账号 |
| 账号授权被收回 | 重载权限与空间，不能通过旧列表继续读取或领取凭证 |
| 模拟切换写入或重启失败 | 在个人设置查看进度及备份；重新发起新票据，不能重复消费旧票据 |

`connections.json` 只保存名称、根地址和设备 UUID，不包含令牌或远端账号快照。系统凭证条目与数据目录、连接 UUID 对应。加密归档仅在本地账号模式提供，不导出或恢复远程设备会话。

桌面已有数据库会在持锁且原密钥有效的条件下，先生成包含 WAL 的 `pre-upgrade-<UUID>.db` 再升级。备份包含加密凭证且仍需要原密钥；保留备份和对应应用版本以便恢复。服务端升级仍须停止全部写入进程、备份数据库与密钥，再执行 `cursor-core ... upgrade`，不能让旧版读取新库。

## 验证命令

```bash
uv run --frozen python -m unittest discover -s tests -p test_v2_connected.py -v
uv run --frozen python -m unittest discover -s tests -p test_v2_upgrade.py -v
npm --prefix frontend run build
npm --prefix frontend run test:connected
npm --prefix desktop test
cargo test --manifest-path desktop/src-tauri/Cargo.toml --bin cursor-panel-desktop
```

浏览器验证启动 `dev/preview-connected.py`，所有数据库、用户、Cursor 凭证、安装和服务端均为隔离 fixture，通过实际 HTTP、浏览器授权页及回环回调验证。测试中的系统凭证库替身与模拟 Cursor 安装不代表真实系统/上游已验收；系统凭证库另有只访问自建合成条目的平台测试。
