# ADR 0006：独立桌面运行与本机数据交付

日期：2026-09-10。状态：实现；平台实测见 [P4 验证报告](../plans/p4-verification.md)。

P4 用 Tauri 2 加载随包的正式 Vue 界面，Python 后台复用 Core 和经过响应模型约束的账号 API。后台仅由私有 stdin 握手取得数据目录与随机通信密钥；随机回环端口拒绝错误 Host、Origin、Sec-Fetch 标记和未认证请求。Rust 接收操作枚举、UUID、查询字段与请求体，构造固定业务路径；没有任意 URL、文件路径、shell 或远端页面桥。桌面前端不持有通信密钥或系统主密钥。

本地模式通过数据目录标记建立单一无密码用户及个人空间，每次启动建立私有短期会话并撤销上次会话，长时间驻留时续建。server 初始化和 Web Cookie 鉴权保持独立，桌面不挂载登录、邀请、团队维护、实例维护或手工脚本接口。

系统主密钥由 Python keyring 的指定原生后端管理：macOS Keychain、Windows Credential Manager。条目按应用数据目录区分；拒绝其他后端与明文回退。数据库存在但密钥缺失时不会生成替代密钥。加密归档包含账号及原实例密钥恢复材料；恢复必须先通过现有数据库密钥校验，再写入系统凭证库。导入要求空个人空间，在同一事务内建立新 UUID、授权代次及目标密钥加密上下文，保留快照时间，不合并或回源。

归档采用固定参数 scrypt（N=32768、r=8、p=1）派生密钥，随机 salt/nonce 与 AES-256-GCM 认证加密，绑定格式头和版本。文件上限 64 MiB，最多 10000 个账号。口令至少 12 个字符，系统文件对话框选取路径；导出拒绝覆盖已有文件。口令只用于此次原生调用，前端不接收账号明文凭证。

本机切换使用随包 Python sqlite3：授权票据签发/领取 → 验证桌面 session 与期限 → 检测安装 → 正常退出 → 等待所有 Cursor 进程退出 → SQLite backup 一致备份 → 事务更新 → 重启。使用完整上游 subject 写入登录字段，SQL 行为与旧固定脚本一致。失败不强杀 Cursor；备份和非敏感进度持久化，操作中断可恢复；恢复前再次备份当前数据库。目标目录锁覆盖不同面板数据目录间的竞争。

主窗口与后台并行启动。后台改为 PyInstaller onedir 资源，避免每次运行解包整个 Python 环境，仍无需用户安装开发工具。启动报告分别测量导入、核心与密钥库、监听器、壳等待和 DOM 就绪。正常应用启用单实例；显式模拟验证模式使用独立临时目录，不激活用户正在运行的实例。

关闭窗口默认退出；用户启用托盘驻留后继续定期刷新。后台一次处理一个账号，每次间隔 30 秒，完成一轮后等待 15 分钟；启动和休眠恢复后延迟随机 30–90 秒，执行前由共用凭证服务检查期限。失败保留最后成功快照。退出关闭父管道，后台停止调度并等待已开始的本机操作收尾，撤销私有会话并释放锁。

P4 不接入远程设备身份、PKCE 或远端本机切换。真实 Cursor 多客户端续期行为仍按 P5 单独验证。开发安装包不等于完成 P6 签名、公证和正式发行；最低操作系统与未实测架构不能仅凭构建配置宣称支持。
