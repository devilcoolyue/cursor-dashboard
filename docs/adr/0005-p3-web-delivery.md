# ADR 0005：P3 Web 与服务端交付

日期：2026-09-10。状态：已采用。

## 决策

Vue 3 / TypeScript / Vite 通过同源 `/api/v1` 访问 P2 核心。API 显式声明响应模型，生成 OpenAPI 与 TypeScript 类型，CI 验证生成结果。主题令牌复用 legacy CSS；Vue 组件替代 PanelUI，保留异步代次、焦点恢复、弹窗滚动与减少动态效果。P0 桌面验证保留独立 `desktop-probe` 构建模式，不把 Web 登录界面误接到 P0 私有协议。

首次管理员初始化保留离线 `server-init`，Web 提供登录、邀请和初始化说明，不增加公开首次注册入口。邀请放在 URL fragment，读取后移除当前历史地址；浏览器持久化只保存显示偏好。

Web 手工切换由两个已认证、CSRF 保护的 POST 完成：issue → consume。票据继续绑定用户会话、账号、空间、授权代次与凭证版本。可信固定脚本生成器在消费票据的同一写事务内运行，生成失败回滚；不在 HTTP 返回原始结构化凭证。脚本中使用经过解析校验的完整 Cursor subject，并把执行到期限制为票据到期。已交付脚本不能撤回，页面不能证明本机执行成功。

远程 CLI 每次隐藏输入密码，建立内存会话、查询后撤销；拒绝重定向，不引入明文会话文件或先于 P5 的长期设备身份。CLI 与 Web 使用相同授权与 CSRF 规则。

服务镜像多阶段构建，非 root、只读根文件系统，数据和独立密钥分卷，运行时密钥只读。单实例锁继续覆盖业务/升级/维护。备份在锁内用 SQLite backup API 复制；恢复需空目录及原密钥，在暂存目录验证后撤销会话/票据，再产生目标库。密钥单独备份，不随数据库归档暗中复制。

## 边界

P3 提供 Web 与服务端部署；V2 周期后台调度、独立桌面、PKCE、设备会话与远程原生切换尚未接入。额度沿用最后成功快照及手工刷新，明细按需查询。生产域名证书签发由部署者的 DNS/网络和 Caddy 完成；本阶段自动验证使用临时数据库与模拟账号。
