# ADR 0004：P2 身份入口、权限与凭证交付边界

日期：2026-09-10。状态：采用。

## 身份入口

V2 使用独立 `cursor-api`，只接受显式 `CURSOR_CORE_MODE=server`、独立数据/密钥路径和固定 `--public-origin`。启动前必须完成 `cursor-core server-init`。首次管理员密码通过终端隐藏输入；允许将同登录标识的 P1 无密码身份初始化为实例管理员，保留原空间，同时补建个人空间。未初始化实例不监听 HTTP，不提供匿名抢占初始化接口。P3 初始化界面可展示引导状态，创建首个管理员仍需本地运维入口。

密码使用标准库 scrypt（N=131072、r=8、p=1），随机 16 字节盐，12–256 字符。每次校验使用约 128 MiB，进程内串行执行哈希计算；登录同时按来源、登录标识和实例限速。未知用户进行相同成本的密码验证。实例管理员可以列出用户、启停用户、查看实例事件；其身份不赋予其他空间的数据权限。

会话是随机 256 位票据，数据库仅保存哈希、独立 UUID、有效期及撤销状态。HTTPS Cookie 使用 `__Host-` 前缀、Secure、HttpOnly、SameSite=Strict、Path=/；12 小时到期，每人最多 20 个有效会话。CSRF 值由随机票据经域分离 SHA-256 生成，数据库保存其哈希；登录或认证后的 `/auth/csrf` 返回 CSRF 值，普通接口不返回会话票据。Host 固定匹配，写请求必须同时通过 Origin 和 CSRF 校验；登录及新用户接受邀请也要求同源。仅本机调试允许 HTTP。

密码变更撤销全部现有会话和未领取票据。离线 `recover-password` 需要数据目录锁，记录 operator 审计，不作为实例管理员的远程代登录能力。P1 其他无密码身份可由运维者用此命令设置密码。旧 PANEL_TOKEN、旧管理 Cookie、请求体中的 user_id/role 均不是认证来源。

## 权限与事务

`policy.authorize` 是账号和空间操作的统一授权入口；`active_user` 每次读取当前用户状态，并对携带 session_id 的 Actor 检查会话有效性。HTTP 只能由随机票据构造 Actor；不带 session_id 的 Actor 只供持有数据库/密钥的本地运维及内部适配使用，不能向公开入口暴露。

Owner/Admin 管理本空间账号；Member/Viewer 依 view/use 授权访问。Viewer 不可获 use，降级时将原 use 降为 view。Owner 转移在 `BEGIN IMMEDIATE` 事务内先释放唯一 Owner 位置，再设置新 Owner；个人空间不允许邀请、转移或删除。管理员不能任免 Admin 或 Owner，普通成员可主动退出团队。

所有搜索、分页、数量、标签统计和额度推算都基于当前用户可见列表。响应 capabilities 表示权限，bootstrap capabilities 表示当前入口是否支持对应产品功能，客户端需要同时满足两者。

角色变更、移除成员、变更账号授权、停用用户会使相关未领取票据失效；恢复原角色或授权也不会恢复旧票据。邀请只保存哈希，绑定邀请邮箱、角色、签发者，7 天到期且只能用一次。已有用户必须登录后接受邀请，邀请不能重设已有用户密码。签发者权限变更或被禁用时撤销未使用邀请，领取时再次检查签发者权限。

业务变更和成功审计同事务提交；审计失败则回滚业务。审计仅保存 UUID、固定动作、结果、时间、服务端 request_id，以及允许的角色、授权对象、权限级别或字段名，不保存密码、邀请原票据、Cookie、AT/RT 或用户输入的资料文本。刷新结果在保存快照的事务内再次检查 use 权限；慢明细、重新授权和票据签发也在完成前复查。外部切换执行结果单独记录，不能将领取成功描述成客户端切换成功。

Owner 删除整个导入空间时，一并删除该空间的导入回执与映射，保留审计。仅删除账号仍保留 P1 回执，重复导入不能复活已删除账号。

## P2 切换交付范围

`SwitchService.issue/consume` 为可信适配提供最多 5 分钟、单次领取的票据。票据绑定用户、Web 会话、空间、账号、授权代次和凭证版本，有效期不超过会话和上游 AT 到期时间。领取事务复查权限、版本和有效期，解密、消费、成功审计一并提交；并发领取最多成功一次。

P2 不挂载返回裸凭证的浏览器 API。Web 手工脚本适配属于 P3；PKCE 设备身份及远程桌面原生领取属于 P5。P2 会话绑定测试不能替代 P5 设备绑定或上游会话竞争验证，API 明确返回 `manual_switch=false`、`device_sessions=false`、`remote_switch=false`。

## 运行边界

单实例、单业务进程，数据目录锁覆盖 HTTP 生命周期和运维升级。API 不读取旧数据库或隐式初始化数据。按用户/账号限制手工回源操作；既有网关继续统一节流。固定 Origin 后的反向代理必须保留 Host；不信任 X-Forwarded-For 作为身份或登录限速依据，代理后的用户共享该代理来源的限额。

P2 没有新版 Web 界面、容器部署、自动后台账号调度、远程 CLI 登录或桌面集成，这些继续由 P3/P4/P5 交付。当前 API 的列表只读最后成功快照，手动刷新及明细按需回源。
