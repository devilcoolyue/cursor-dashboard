# ADR 0007：桌面设备身份与远程连接边界

日期：2026-09-10。状态：实施；真实 Cursor 远程切换尚未开放。

## 决策

桌面通过随包 Python 后台访问用户明确配置的实例根地址。外部地址必须为 HTTPS，本机调试允许 HTTP 回环地址。请求不跟随重定向，不继承环境代理或 Cookie；Tauri 和后台各自维护固定操作白名单。WebView 不具备任意 URL 请求、设备令牌读取或结构化凭证领取方法。

系统浏览器打开实例的 `/#/device` 页面，使用现有 Web 登录及 CSRF 保护进行显式授权。原生后台在 `127.0.0.1` 随机端口临时监听固定 `/callback`；校验精确 Host、路径和随机 state。只支持 S256 PKCE，授权码绑定浏览器会话、challenge、回调地址和设备 UUID，保存哈希，有效期最多 120 秒，事务内单次交换。原生等待窗口最多 5 分钟，取消或更换连接使旧回调失效。

设备身份复用 `user_sessions` 的撤销与事务授权规则，增加 `kind=device`、设备 UUID 和名称。选择复用而非第二套身份鉴权，是为了让密码修改、用户停用、会话撤销、慢请求复查及切换票据绑定继续使用同一条规则。网页 Cookie 只接受 `kind=web`，原生 Bearer 只接受 `kind=device`；设备专属接口拒绝网页认证和浏览器请求头。设备最长登录 30 天，到期重新打开系统浏览器登录，同一安装重新登录会撤销其旧会话，其他设备不受影响。

连接名称、根地址和设备 UUID 保存于受限的 `connections.json`；长期设备令牌单独保存在系统 Keychain / Credential Manager 的 `dev.cursor-panel.desktop.devices` 服务下。令牌、授权码及 verifier 不写日志、前端持久化或归档。连接切换清空身份、空间和界面查询数据，终止浏览器请求作用域；不可取消的已发原生 HTTP 请求在后台和前端按代次拒绝旧结果。本地调度只处理本地库，远程账号按需调用实例 API，不在本机启动第二套 Cursor 查询或续期。

原生结构化切换沿用共用一次性票据，绑定用户、准确设备会话、空间、账号、授权代次、凭证版本和有效期。凭证仅从原生 HTTP 通道交给固定本机执行器，结果单独审计。执行失败不重用票据；写入、WAL 备份和恢复继续遵守 P4 的规则。

## 未验证能力的处理

本项目的设备会话独立性不等于 Cursor 上游会话独立性。服务端与 Cursor 共享 RT 时，服务端数据库锁无法协调独立客户端。S01–S06 真实实验仍缺少专用会话及多设备证据，因此生产 `remote_switch=false`，服务端签发/领取和原生执行均拒绝。没有环境变量或命令行开关可以开放；私有 `_device_switch_test` 构造参数只供合成测试入口使用，不接入生产运行配置。

不能因模拟原生切换成功把整个 P5 或 V2 Connected Desktop 标记为完全验收。远程查看、按权限管理及设备会话可单独交付，真实切换待上游矩阵及目标平台验证通过后另行启用。

## 升级

Alembic `0003_devices` 通过新增列与授权码表升级，不重建被切换票据引用的会话表，避免 SQLite 外键级联删除。已有会话默认 `kind=web`。独立桌面在数据目录锁内、验证原密钥后先备份旧库，再升级；服务端继续使用停止进程后的显式升级。运行校验报告读取实际 schema 版本。
