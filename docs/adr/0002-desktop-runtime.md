# ADR 0002：Tauri 与随包 Python 的桌面运行方式

日期：2026-09-09；收尾：2026-09-10。状态：采用，平台结果见 [P0 报告](../plans/p0-verification.md)。

## 决策

采用 Tauri 2 + Vue 3 + 随包 Python。macOS arm64 与 Windows x64 已通过构建、安装产物运行、凭证库和退出清理验证。Python 用 PyInstaller 构建宿主平台的单文件后台，Tauri 将它作为 externalBin 打包；后续生产发行是否改为目录形式，以签名、启动性能及更新验证决定。

桌面只加载安装包前端，前端仅能调用固定的 `probe` 和 `frontend_ready` 命令。Rust 原生层启动后台并持有通信密钥，通过有限方法请求固定回环 API；无通用 URL 代理、shell 插件或前端文件系统能力。

启动密钥通过继承的 stdin 管道传递，后台绑定随机端口，通过 stdout 只返回就绪端口、PID 和协议版本。API 校验密钥与 Host，拒绝带 Origin/浏览器 fetch 标记的调用。密钥不进入前端、URL、进程参数或环境变量。

正常退出时关闭管道并等待后台结束。父进程被终止时管道 EOF 同样触发后台退出，验证需覆盖 PyInstaller 引导进程及实际 Python 子进程；启动失败明确展示错误。

系统凭证库采用 keyring 的平台原生后端；P0 只创建随机合成条目，读回比较后删除，不枚举或读取现有条目。探测结果不包含条目值。生产主密钥管理和锁定/恢复由 P1/P4 实现。

## 验证范围

- 随包前端渲染两个 `.test` 模拟账号，并在 Vue `nextTick` 后向原生层确认 DOM 数量。
- 独立工作目录及包含中文/空格的重定位路径，移除 PATH 中 Python/Node/uv 等开发工具。
- 冻结后台中的 FastAPI、Uvicorn、SQLite 和 fixture 均可用；本机无真实 Cursor 文件访问和上游请求。
- 报告启动时间、安装产物大小及进程树 RSS。RSS 可能重复计入共享页，macOS 系统托管的 WebView 进程可能不在子树，不能将其称为完整应用内存。

“移除开发工具的 PATH”验证运行时独立性，不等同于已在所有全新操作系统上完成安装。Windows WebView2 和 macOS 最低系统版本另行记录，正式签名/公证与升级恢复属于 P4/P6。

本机 macOS 界面就绪约 1.86 秒；最终 CI 的 Windows 首次约 18.76 秒，随后一次约 1.83 秒。首次启动耗时仍需 P4 分段测量和优化；P0 没有据此作出固定启动时间或内存上限承诺。采用结论以打包和系统适配可行性为依据。

## 远程登录预案

P5 优先系统浏览器 + 临时 loopback 回调 + PKCE S256：绑定 state 与精确回调地址、授权码单次领取、设备会话可撤销。P0 只验证本地后台通道；PKCE 回调、设备会话和远程实例信任需要 P5 单独验证，不复用本地探测密钥。

Electron 是平台兼容验证无法满足要求时的备选。是否切换框架以平台实测为依据，业务核心和共享前端不随壳框架更改。
