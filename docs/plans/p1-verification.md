## 交付范围

- `CoreConfig`、`Core` 与数据目录锁：显式组装数据库、密钥、网关和服务，无导入时新库初始化；升级与运行互斥。
- domain/application/infrastructure/runtime 分层：账号授权、额度、明细、快照与续期用例可脱离 FastAPI 调用。既有面板刷新复用查询用例，Cursor 授权协议移入共用适配层。
- SQLAlchemy + Alembic `0001_core`：用户、空间、成员、账号、凭证、标签、账号授权、快照、续期租约及导入记录。稳定 UUID、空间外键和唯一约束代替全局邮箱标识。
- AES-GCM 凭证加密与 KeyProvider：空间/账号/代次/版本作为 AAD，普通列表不含凭证；启动检查密钥，支持原密钥恢复。
- 数据与并发规则：正常轮换保留快照，重新授权变更代次，过期租约和旧请求不能提交；明细缓存有限且按空间、账号、代次、账期隔离，套餐推算只读取当前可见账号。
- `cursor-core`：密钥生成、初始化、空间创建、旧库预检/导入、校验、升级、列表、单账号刷新与明细；wheel 安装后可运行。

P1 的 V2 核心通过本地运维入口使用。旧面板与 CLI 保留原数据库/鉴权兼容入口；完整用户认证、邀请、授权管理和 HTTP 接入在 P2/P3 实施。P0 桌面仍使用模拟后台，正式接入在 P4。
