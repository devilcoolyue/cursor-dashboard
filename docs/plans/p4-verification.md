- 系统应用数据目录、应用/目录单实例、健康状态、退出清理、可选托盘驻留与休眠恢复错峰刷新。

- macOS/Windows 默认路径检测、正常退出、WAL 一致备份、事务更新、完整 subject、重启、持久进度与恢复入口。

- PyInstaller onedir 随包运行时、并行壳启动、分段启动测量、macOS arm64/x64 与 Windows x64 CI 构建矩阵。
