## 验证边界

所有账号和数据库均为合成临时数据。未读取真实 Cookie、AT/RT 或 Cursor 数据库，未切换用户 Cursor。模拟产物使用自己的临时数据目录，不激活机器上已运行的真实面板。

原生 GUI 测试覆盖真实 OS 适配路径，但不等同于真实 Cursor 上所有保存提示、重启或上游续期行为都已验证。运行时独立性通过移除 PATH 与重定位检查；CI runner 本身安装有开发工具，尚未验证全新无开发工具设备。

macOS 最低版本配置为 12.0，Windows 使用系统 WebView2；最低系统版本、WebView2 缺失时的引导安装、正式签名与公证尚未验证，不据此宣称支持。Linux、便携版与自定义 Cursor 数据目录不在本轮范围。

P4 提供独立本地桌面。真实上游多客户端续期与撤销矩阵仍待 P5 专用测试会话验证；PKCE、设备会话与远程原生切换未交付。
