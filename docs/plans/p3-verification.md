## 交付内容

- Vue 登录/首次使用说明、邀请加入、个人/团队账号、搜索/标签/分页、额度/模型明细、添加/重新授权/编辑/删除/刷新、凭证时间和状态。
- 根据 capabilities 展示成员/授权/Owner 转移/团队删除/实例用户启停；个人设置支持密码、会话和显示偏好。
- Python 响应模型、生成 OpenAPI/TypeScript 类型及漂移检查；Hash 路由与同源 API、过时响应丢弃、用户/空间缓存清理、弹窗焦点与滚动约束。
- 绑定当前 Web 会话的一次性手工切换票据，固定 macOS/Windows 脚本生成与消费同事务；关闭/到期清除脚本。模拟预览脚本访问本机前停止。
- Docker 多阶段镜像、Compose/Caddy、非 root 与独立持久数据/密钥卷、健康检查、离线一致备份和空目录恢复；恢复撤销旧会话与票据。
- `cursor-remote` 隐藏密码输入、内存会话、版本校验、同一 API 权限、结束撤销；安装 wheel 内的 Web 与 CLI 验证。
- P0 桌面验证保留独立构建模式。
