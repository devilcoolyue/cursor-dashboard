# v0.0.1 版本归档

本版将 P0–P6 与侧栏导航阶段的最新代码合并至 `main`，以 `v0.0.1` 标签保存发布源码。此前开发阶段沿用的 `1.4.0` 改为本次发布序列 `0.0.1`；Python、Web、桌面、容器默认版本及依赖锁中的本项目版本保持一致。API 主版本仍为 `1`，数据库 schema 为 `0003_devices`。

## 本版内容

- 个人与团队空间、账号授权、额度快照和模型用量明细，支持已认证 Web、远程 CLI 与独立桌面。
- 新侧栏导航、空间切换、标签筛选、账号卡片和分区设置；支持折叠侧栏、移动布局、六种皮肤与独立明暗偏好。
- Web 提供一次性短命令下载固定切换脚本；本地桌面支持原生切换和受保护的临时脚本命令。
- 桌面通过系统浏览器登录远端，使用 PKCE 和系统凭证库管理可撤销的设备会话。
- 加密凭证、离线备份恢复、加密账号归档、手动更新和安装包来源/完整性校验。

## 已知边界与更新

桌面安装包为未发行者签名、未公证的早期版本，清单继续使用 `v2-preview` 通道。macOS/Windows 可能显示来源或签名提示；SHA-256 仅用于完整性校验。真实远程 Cursor 切换保持关闭，Linux 原生桌面与 Windows arm64 不在本次范围。

此前安装过 `1.4.0` 开发候选的用户应遵循[手动更新和回退流程](../v2-release-operations.md)：先退出应用并备份完整数据目录、匹配密钥和旧安装包，再手工安装本版。版本序列调整不执行数据库降级，不应让旧程序打开新 schema。平台与真实会话验证边界见[支持表](../supported-platforms.md)。
