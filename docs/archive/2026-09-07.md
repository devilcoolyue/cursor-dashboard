## 关键纠正

| 原说明问题 | 代码依据与当前结论 |
|---|---|
| 常规取数交替写为 4/5 个网页接口 | `client.DESKTOP_ENDPOINTS`、`server.refresh_account`、`cli.query_accounts` 实际使用 6 个桌面请求；旧网页方法仍保留但不是主路径 |
| 所有 API 都用面板口令，持有口令即可切换所有账号 | `require_token` 允许管理员会话；管理 API 独立鉴权；`require_switch` 再检查开放范围 |
| 部门权限易被理解为使用者权限隔离 | 普通账号修改接口允许调整部门，切换范围按目标当前部门计算；这是共享入口，不是按访客身份授权 |
| 管理页被写成独立前端 | `/admin` 与 `/` 返回同一个模板，管理片段注入页面，`setWorkspace` 在同文档内切换 |
| 只记载两种皮肤及剩余额度排序 | `SKINS` 为 6 种；另有重置时间排序与当前部门内搜索 |
| 所有出站请求严格统一限速，周期是实际刷新时长 | 外层排任务时槽，内部重试独立退避；每账号查询结束后还要等待，周期仅为目标；恢复计数并非严格连续成功 |
| 同套餐上限会自动随套餐变更准确更新 | `pools` 基于同名套餐观测估算，缺少 TTL 与删除/换套餐清理，可能滞后 |
| Grok 总是按起点加 7 天，失败只影响该行 | 优先明确重置时间；普通错误省略该行，认证和限流参与整个刷新判定 |
| 所有默认数据库路径都是工作目录固定文件 | 未指定 `DATABASE_PATH` 时从 `ACCOUNTS_PATH` 推导 `.db`；父目录需预建 |
| 模拟预览及脚本存在即意味着可用 | 旧 `preview.py` 未适配管理片段；本次验证通过的是 `preview-admin.py` 与 `verify-admin.js` |

CLI 的 `-c` 分支已核实为临时读取 JSON、每次换取桌面凭证、不读写本地账号库；默认 CLI 使用共享库并持久化续期，但不更新面板快照。两种行为已分别说明。

## 遗留边界

- 旧 `preview.py` 及 3 份动效/切换浏览器脚本待适配管理模板；`preview-admin.py` 仍依赖其数据函数，不能直接删除。阶段内保留实现并撤下可用流程的描述。
- 权限只支持共享面板入口和单一管理员身份；没有普通用户、只读角色、部门数据隔离或完整操作审计。
- 同套餐额度估算没有观测过期清理；多进程部署没有调度、快照与限速同步；快照落盘异常不向页面报告。文档已明确这些边界。
- 无内置历史趋势、告警推送、备份恢复页面、自动获取浏览器 Cookie、Linux 本机切换或自定义用户数据目录支持。
- 本次未重跑真实 Cursor 额度接口、双账号网页退出实验、真实客户端切换、Windows PowerShell、Linux systemd 部署。模拟测试通过不能替代这些外部验证，也不能延续旧文档对实际会话寿命的保证。
