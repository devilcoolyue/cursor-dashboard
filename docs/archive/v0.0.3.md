# v0.0.3 版本归档

v0.0.3 集中处理长期运行后的磁盘占用、代理来源识别和移动端导航体验。Python、Web、桌面及随包后台统一为 `0.0.3`，API 主版本保持 `1`，数据库 schema 升级为 `0004_retention`。

## 新增与改进

- **审计与认证记录保留**：审计默认保留 90 天且全实例最多 100,000 条；服务端和桌面后台分批清理过期审计、网页会话、设备授权、邀请与切换票据。可通过环境变量调整正整数上限。
- **离线数据库维护**：新增 `cursor-core maintain`，停止服务后可用 `--compact` 执行 WAL checkpoint 与 `VACUUM`，回收大量历史删除留下的 SQLite 空闲页面。数据目录锁仍阻止与运行中实例并发维护。
- **数据库索引**：schema `0004_retention` 为全局和空间审计时间线增加复合索引；相同时间的审计事件使用稳定的 ID 倒序。迁移只增加索引，实际删除由保留任务执行。
- **账号切换备份**：原生切换和 Web 终端脚本最多保留 20 份、合计 512 MiB；最新备份和当前恢复来源始终受保护，只处理符合程序命名规则的普通文件。
- **客户端更新备份**：完整应用更新备份最多保留 3 份、合计 1 GiB；当前恢复点始终保留，超过 24 小时的中断临时副本会在后续更新时清理。旧 schema 的 `pre-upgrade` 数据库备份采用相同数量和空间预算。
- **服务端更新恢复点**：更新器登记并保留最近 2 个成功升级的原数据卷、镜像和部署配置。超过上限时只回收带本更新器所有权标签、且未被容器引用的数据卷；失败候选在回滚完成后回收，存在恢复日志时暂停清理。
- **可信代理边界**：新增 `CURSOR_TRUSTED_PROXIES` 和 `--trusted-proxies`，只接受明确 IP 或受限 CIDR，拒绝通配符与全网段。标准 Compose 固定 Caddy 地址并覆盖客户端提供的 `X-Forwarded-For`，让代理后的登录限流按真实来源隔离。
- **部署容量控制**：标准 Compose 为 panel、maintenance 和 proxy 启用 Docker `json-file` 日志轮转，每份 10 MiB、最多 5 份；代理网络、动态分配段和固定地址可在 `.env` 中调整。
- **移动端侧栏**：导航改为带遮罩的左侧抽屉，限制宽度并锁定背景滚动；支持点击遮罩和 Escape 关闭、Tab 焦点循环、关闭后恢复焦点，以及减少动态效果偏好。
- **依赖维护**：Python `cryptography` 升级到 `50.0.1`，主程序与桌面 sidecar 锁文件同步更新。

## 安装与升级

[GitHub Release v0.0.3](https://github.com/devilcoolyue/cursor-dashboard/releases/tag/v0.0.3) 提供 macOS Apple Silicon / Intel DMG、Windows x64 安装程序、Linux amd64 镜像、Python wheel、源码、验证记录及 SHA-256 校验文件，并提供桌面与服务器签名更新产物。

- **客户端从 v0.0.2 升级**：可在「关于与更新」中检查并安装签名更新。安装前仍建议导出加密归档；更新器会在替换应用前创建完整恢复点。
- **服务端从 v0.0.2 升级**：先保存数据库与匹配主密钥的外部备份，再执行升级。新版本将 schema 升至 `0004_retention`；不要让 v0.0.2 直接打开升级后的数据库，也不要运行 Alembic downgrade。
- **Compose 网络**：默认网络为 `172.30.87.0/24`，代理固定为 `172.30.87.2`。若与宿主现有网络冲突，须一起调整 subnet、dynamic range 和 proxy IP，并在维护窗口重建网络与容器，不能使用 `down -v`。
- **保留策略**：上线前根据合规与容量需求设置 `CURSOR_AUDIT_RETENTION_DAYS` 和 `CURSOR_AUDIT_MAX_EVENTS`；默认值会在后台运行后开始清理，不应把应用数据库作为长期审计归档。
- **回退**：保留旧安装包或镜像、外部数据库备份和匹配密钥。schema 升级后按发行运维文档恢复到空数据目录，不使用旧程序读取新数据库。

## 验证与边界

发布前本地检查覆盖 347 项 Python 回归、前端类型检查与生产构建，以及 Rust 桌面路由和备份保留测试。PowerShell 专属场景由 Windows CI 执行；三平台候选构建、安装、浏览器流程和签名更新产物以本版本 GitHub Actions 与 Release 附件为准。

桌面产物仍使用 `v2-preview` 通道，没有 Apple Developer ID 签名 / 公证或 Windows Authenticode。更新包签名只验证更新来源，不能替代操作系统发行者签名。真实远程 Cursor 切换继续关闭；真实多设备续期、最低系统版本与所有全新设备安装链路不属于模拟验证结论。Linux 原生桌面、Windows arm64 不在当前支持范围。
