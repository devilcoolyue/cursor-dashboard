# v0.0.2 版本归档

v0.0.2 集中改进首次使用、账号展示、Cursor 安装路径兼容和更新体验。Python、Web、桌面及随包后台统一为 `0.0.2`，API 主版本保持 `1`，数据库 schema 保持 `0003_devices`。

## 新增与改进

- **品牌与入口**：统一 Web、桌面和旧版入口的图标；macOS 图标增加系统应用所需的外侧留白。启动页显示加载状态、失败原因与重试；统一登录、邀请和实例连接页面的布局与反馈。
- **新手指引与文档**：客户端首次打开提供六步指引，可跳过、继续或重新阅读；内置 14 个可搜索的离线帮助模块。README 默认英文，提供中文版、语言切换、浅深色模拟截图、下载入口及 macOS 未签名安装包的打开说明。
- **账号卡片**：支持 12 项显示设置、精简预设与恢复默认，包括套餐、邮箱、标签和额度上限；设置只影响展示，不改变额度查询与账号权限。
- **额度上限**：本次观测无法反算上限时，按条件沿用本账号同套餐、同账期的有效历史观测；仍可在可见同套餐账号范围内估算。标明推算来源，缺失时显示未知，不以套餐包含金额替代额度池上限。
- **交互修复**：统一鼠标与键盘焦点行为，修复关闭弹窗后提示浮层重新出现；帮助与显示偏好的箭头随开合平滑旋转，并尊重减少动态效果设置。
- **Cursor 路径**：Windows 扩展运行进程、PATH、注册表及快捷方式发现；支持手动指定程序与用户数据目录、便携安装和重新检测。保存前验证路径与数据库，多实例或进程访问冲突时停止切换。
- **更新能力**：品牌版本徽标、每四小时更新检查、手工检查和「关于与更新」页面。客户端支持签名更新包、升级前备份和重启；标准 Linux amd64 Compose 部署可安装可选宿主机更新服务，在数据副本上升级并在失败时回退。
- **发布检查**：补齐路径测试的开发依赖；更新界面测试使用高于当前版本的模拟版本；三平台页面 CI 增加启动、卡片显示和更新流程检查。
- **macOS 打包完整性**：打包时使用 ad-hoc 本地签名，并执行 `codesign --verify --deep --strict`；这只保证包内签名完整性，不提供 Apple Developer ID 身份或公证。

## 安装与升级

[GitHub Release v0.0.2](https://github.com/devilcoolyue/cursor-dashboard/releases/tag/v0.0.2) 提供 macOS Apple Silicon / Intel DMG、Windows x64 安装程序、Linux amd64 镜像、Python wheel、源码、验证记录及 SHA-256 校验文件，并提供桌面与服务器签名更新产物。

- **从 v0.0.1 升级客户端**：先导出加密归档，完全退出应用并备份数据目录，再手动安装 v0.0.2。v0.0.1 未内置本次更新器，不能直接使用本版新增的一键升级；安装 v0.0.2 后可用于后续版本。
- **macOS 无法打开**：当前应用没有 Apple Developer ID 签名与公证；确认来源和校验后，按 [README 的处理步骤](../../README_CN.md#macos-提示已损坏或无法打开怎么办)操作。移除单个应用的下载隔离标记不会使其成为已签名应用。
- **服务器升级**：先停止服务并备份数据库与匹配密钥，再使用新镜像执行 `cursor-core upgrade`、`cursor-core verify` 后启动，详见 [Web 运维](../v2-web-operations.md)。可选自动升级服务的一次性配置见[自动升级](../automatic-updates.md)。
- **回退**：保留旧安装包或镜像及匹配的数据备份，按[发布与恢复流程](../v2-release-operations.md)操作，不使用旧程序直接打开新版数据库。

## 验证与边界

发布使用隔离数据、模拟 Cursor 网关和独立测试应用，覆盖 Python 核心、桌面后台、Rust 固定路由、Web / 桌面 / 远程连接、Chromium / WebKit 启动与显示设置、签名校验和更新失败恢复。跨平台安装与容器验证记录随 Release 的验证归档提供，具体提交及工作流运行以发布记录和各产物清单为准。

桌面产物仍使用 `v2-preview` 通道，没有 Apple 发行者签名 / 公证或 Windows Authenticode。更新包签名用于验证更新来源，不能替代操作系统发行者签名。真实远程 Cursor 切换继续关闭，真实多设备续期、最低系统版本与所有全新设备安装链路不属于模拟验证结论。Linux 原生桌面、Windows arm64 不在当前支持范围，详见[平台说明](../supported-platforms.md)。
